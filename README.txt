UrbanGift demo website
1. Open index.html in a browser.
2. Replace the WhatsApp number in the JavaScript if your business WhatsApp number is different.
3. Replace product names/prices in the PRODUCTS array.
4. The supplied UPI QR is saved as upi-qr.jpg.
IMPORTANT: This is a front-end demo. For a real store, use a secure backend/database, HTTPS, server-side order validation, authentication/admin panel, and a proper payment gateway/webhook. A browser-only site cannot guarantee protection from hacking.
